# 搜索工具用途与选择

下表将最初的工具比较整理成 Agent 的选用指南。强项、弱项属于使用场景判断，不是本项目做出的统一性能测试或绝对排名；实际效果取决于查询、领域、语言、索引和账户权限。

| 工具 | 本质 | 主要用途 | 选择时留意 |
| --- | --- | --- | --- |
| AnySearch | 面向 Agent 的搜索基础设施 | 通用及垂直领域检索、多源信息 | 垂直 tag/params 先查询能力定义，成熟度需在实际任务中验证 |
| Tavily | AI Search API | 通用 Agent 搜索、研究、RAG | 深入搜索使用 advanced 并消耗更多额度；召回质量需按任务评估 |
| Exa | 语义与 Web 搜索 | 相似内容、文章、论文、公司检索 | 语义相关性和搜索深度是不同维度，不能从片段推断已读全文 |
| Firecrawl | 网页抓取、内容解析及搜索 | 已知 URL 读取、Markdown、站点 Crawl | 整站抓取明确设置页数上限；搜索后通常还需要正文读取 |
| Brave Search API | 独立索引的搜索 API | 通用 Web、自己搭建搜索/RAG 流程 | 返回搜索资料，由 Agent 自己整理、引用和验证 |
| Perplexity | 搜索 API 与模型研究回答 | 结构化检索或带引用的综合回答 | search 与 answer 的输出和费用不同；当前回答使用 Agent API |
| Grok | 模型结合原生搜索工具 | 新闻、实时网页、X 社媒内容 | web_search 与 x_search 区分；平台和模型可用性影响功能 |
| 秘塔 / Metaso | 搜索与答案生成产品及 API | 中文资料、指定数据源查询 | 网页端和 API 额度不同；当前适配器包装 search/read |
| Context7 / CT7 | 开发文档检索 | Library/API 文档、代码示例与版本查询 | 不是通用新闻或学术搜索；检查实际服务的文档版本 |
| Consensus | 学术论文与研究证据检索 | 论文、研究结论、科学证据 | 论文结论不代表领域共识；全文片段和额度取决于账户 |

Skill 的默认路由见 [SKILL.md](../SKILL.md)，接口依据见 [providers.md](providers.md)。优先遵守用户指定的工具；需要交叉核查时显式选择多个后端并检查 provenance。
